# Tienda de Juegos

Catálogo de juegos PC / APK con etiquetas, autenticación y rol de administrador.

## Stack

Python · Flask · SQLite · Jinja

## Desarrollo

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
set SECRET_KEY=una-clave-local
python app.py
```

La base `tienda_juegos.db` se crea sola y no se versiona.
